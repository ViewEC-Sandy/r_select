# Product Database V1.2.14

## 文字型數值自動轉換
所有匯入報表在寫入 Firestore 前，會先將已知數值欄位轉成 JavaScript Number。

支援：
- Excel「數字以文字儲存」
- 1,234 / 1,234.56
- NT$1,234 / TWD 1,234
- ￥5,000 / ¥5,000 / JPY 5,000
- 全形數字，例如 １２３４
- 括號負數，例如 (1,234) → -1234

套用欄位包含：
- 商品主檔：價格、台幣售價、日幣售價、重量
- 台灣樂天：頁面檢視、售出單位、訂單計數、顧客已付金額、運費
- Shopline：付款總金額、運費、商品結帳價格、數量
- 店鋪：運費

商品管理編號、商品規格管理編號、訂單號碼、SKU、店鋪編號等識別欄位不會轉成 Number，避免前導 0 或編碼格式被破壞。
