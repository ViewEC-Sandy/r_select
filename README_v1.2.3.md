# Product Database v1.2.3 更新說明

1. 銷售狀態新增「營業額(TWD)」與總營業額 KPI，可依銷售日期區間篩選，且「顯示欄位」可自訂。
2. 店鋪編號顯示為可點擊超連結，網址來自店鋪資料的「網址」欄位，亦可在店鋪管理修改。
3. 台灣URL讀取「商品網址」；日本URL讀取「參考URL #1」，兩者均可在商品編輯中修改。
4. 銷售報表若含「訂單號碼 / 顧客已付金額 / 運費」，營運總覽與平台比較會以訂單號碼唯一去重，只計一次顧客已付金額及運費。
5. 舊銷售資料沒有訂單層資料時，營業額仍以銷售數量 × 商品售價作為相容性估算。

部署：解壓縮後覆蓋 GitHub 專案檔案。請保留你現有的 firebase-config.js 設定。
