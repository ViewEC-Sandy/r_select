# Product Database V1.2.5

## 更正內容

### 1. 台灣樂天銷售報表
增加讀取「訂單日期」。

### 2. 新增日安優物 Shopline 銷售報表
- 訂單號碼：唯一訂單參考值
- 訂單日期：日期
- 付款總金額：訂單總營業額
- 運費：已收運費
- 商品貨號：商品管理編號
- 商品結帳價格：商品層級營業額分配依據
- 數量：銷售商品數

總營業額仍依訂單號碼去重後加總付款總金額。

### 3. 移除匯入功能
- 上傳樂天廣告 CSV
- 上傳商品分析 CSV

Firestore 平台 ID 保留 `rianyou_shopify`，僅更新顯示名稱為「日安優物 Shopline」，以維持既有資料相容性。
